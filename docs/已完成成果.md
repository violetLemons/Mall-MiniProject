### 修改文件清单

**模型层：**
- `miniprogram/models/product.ts` — `ProductCategory` 新增 `parentId?` / `children?` / `isPrimary?` 三个可选字段（两级分类）。该文件为纯类型声明，编译产物 `product.js` 无运行时变化（未改动）。

**服务层：**
- `miniprogram/services/category.service.ts` + `.js`
  - `getQuickCategories()` 改为只返回**一级分类**（调用 `products.categories` 时传 `parentId: ''`），供首页金刚区使用。
  - 新增 `getCategoryTree()`（调用 `products.categoryTree`），返回一级分类内嵌 `children` 二级分类数组，供分类页使用。
- `miniprogram/services/order.service.ts` + `.js`
  - 新增 `ORDER_STATUS_TOKEN` 常量，统一订单列表组合状态 token（`ALL` / `PENDING_PAYMENT` / `PAID` / `SHIPPED` / `REFUND` / `PENDING_REVIEW` / `COMPLETED`），与后端 `orders.list` 的过滤逻辑一一对齐。
  - `OrderModel` 新增评价相关可选字段：`reviewed?` / `reviewRating?` / `reviewComment?` / `reviewedAt?`。
  - 新增 `submitReview(id, { rating, comment })`（调用 `orders.review`，评价后 `reviewed=true`，从「待评价」归入「已完成」）。
- `miniprogram/services/activation.service.ts` + `.js`（**新增**）
  - `ActivationService.redeem(code)`（调用 `activation.redeem`），返回 `ActivationRedeemResult`（`code` / `type` / `benefit` / `value`）。

### 与后端契约对齐

| 前端调用 | 后端云函数 action | 说明 |
| :--- | :--- | :--- |
| `products.categories`（`parentId:''`） | `categories` | 只取一级分类 |
| `products.categoryTree` | `categoryTree` | 两级分类树 |
| `orders.list`（`status` token） | `list` | 支持 `REFUND` / `PENDING_REVIEW` / `COMPLETED` 等组合 token |
| `orders.review` | `review` | 订单评价 |
| `activation.redeem` | `redeem` | 卡密兑换 |
