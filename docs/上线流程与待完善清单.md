# 公司自营水果小程序：上线流程与待完善清单

更新日期：2026-10-09。本文按代码、测试和操作日志更新；红色“已完善”只代表相应子项在本地实现并验证，不代表云端部署、微信真实交易验收或审核通过。历史检查和失败修正记录见 [accepted.md](accepted.md) 第11、12节。

## 1. 已确认的业务规则

- 公司主体，自营销售水果；营业执照即将取得，不能记作已经取得。先按新鲜整果实施，鲜切、果汁、加工食品须另行核对资质。
- 每商品仅一个有效SKU，无多规格、无库存控制、无自提、无分账。
- 购物车一起付款，但每件拆成一个独立订单；同商品购买两件生成两单。普通JSAPI的一笔支付关联隐藏付款汇总记录，不采用服务商合单或分账。
- 未付款时，取消一个分单会取消整个付款批次；付款后各分单独立发货、申请售后及退款。
- 收货完成后仍可申请质量售后。管理员审核，可记录理由批准免退货退款；退款单位为一件订单，不增加单件内部比例赔付或自动补发。
- 商家在后台配置配送范围、首件及续件运费；规则按区县、城市、省份、默认规则的精确层级匹配，未匹配或禁止配送的地址不能下单。
- 付款后48小时内发货，以核验的实际支付时间起算。运费按件分摊并保留整数分余数，额度按订单顺序分配；分单退款使用原支付总金额与本分单现金金额。
- 当前每次结算最多10种商品、每种最多5件；一个微信支付批次最多15个不同实物包裹，多个分单可以关联同一运单。

### 水果资质和售后要特别区分

销售食用农产品属于不需要食品经营许可的情形；仅销售预包装食品则涉及另行备案。因此若是新鲜整果，不能简单认定“还缺食品经营许可证”；若增加加工食品，应重新核对。平台类目审核、商品质量安全及实际经营条件仍需满足。[市场监管总局办法第4、5条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_91a91c26ae464a2f898952d5b84f62c6.html)

鲜活易腐商品有七日无理由退货例外，但不免除质量问题的售后责任；不适用无理由退货的商品应明确标注。页面不能笼统写“水果不退不换”。若此前已对消费者作出更有利承诺或成交，应结合当时承诺处理，不能用新规则追溯撤销。[消费者权益保护法第24、25条](https://www.samr.gov.cn/zt/ndzt/2019n/bjspjsqjxcjwljxyjsckpxc/zcfg/art/2023/art_5004b2b0f4154c76acfca499fe9c737a.html)、[退货暂行办法第20条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_26ca8fe29e184edd899fa0a7a060d935.html)

首页还应有经营主体、营业执照及有关许可信息的显著公示或链接，准备合法的购货凭证/开票流程；没有必要为了开票重写一套税务系统。[电子商务法第14、15条](https://www.samr.gov.cn/zfjcj/tzgg/art/2023/art_d337c3291e8b40459ca03dea54395856.html)
